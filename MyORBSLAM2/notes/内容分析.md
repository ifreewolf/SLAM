```bash
# rgbd_tum.cc main
1.LoadImages：根据fr1_xyz.txt文件，读取RGB图像、Depth文件的路径和时间戳
2.构造SLAM对象：System(strVocFile, strSettingsFile, mnsenor, bUseViewer)# 字典树，配置文件，传感器类型，是否需要查看
    2.1 读取配置文件：cv::FileStorage fsSettings(strSettingsFile.c_str(), cv::FileStorage::READ)
    2.2 创建ORB字典对象：new ORBVocabulary # 通过字典树对象加载字典文件
    2.3 创建关键帧数据库：new KeyFrameDatabase(*mpVocabulary) #字典树对象作为参数，保存ORB描述子倒排索引，可以根据描述子查找该描述子的关键帧
    2.4 创建地图：new Map()
    2.5 创建帧绘制器：new FrameDrawer() # 被Viewer使用
    2.6 创建地图绘制器：new MapDrawer() # 被Viewer使用
    2.7 创建Tracking线程：new Tracking(this,mpVocabulary,mpFrameDrawer,mpMapDrawer,mpMap,mpKeyFrameDatabase,strSettingsFile,mSensor); 
                                # System对象，字典,         帧绘制器，   地图绘制器，  地图， 关键帧数据库，        配置文件，       传感器类型
    2.8 创建LocalMapping线程：new LocalMapping(mpMap, mSensor == MONOCULAR) # 地图，    是否单目
                            new std::thread(&ORB_SLAM2::LocalMapping::Run, mpLocalMapper); # 运行LocalMapping中的run方法
    2.9 创建LoopClosing线程：new LoopClosing(mpMap, mpKeyFrameDatabase, mpVocabulary, mSensor != MONOCULAR); 
                                           # 地图，  关键帧数据库，       ORB字典，     是否是单目
                           new std::thread(&ORB_SLAM2::LoopClosing::Run, mpLoopCloser); # 运行LoopClosing中的run方法
    2.10 创建观察器线程：new Viewer(this, mpFrameDrawer, mpMapDrawer, mpTracker, strSettingsFile);
                             # System对象，帧绘制器，   地图绘制器，  跟踪对象，   配置文件
                      new std::thread(&Viewer::Run, mpViewer) # 运行Viewer中的run方法
    2.11 设置线程间通信：mpTracker->SetLocalMapper(mpLocalMapper)
                      mpTracker->SetLoopClosing(mpLoopCloser)
                      mpLocalMapper->SetTracker(mpTracker)
                      mpLocalMapper->SetLoopCloser(mpLoopCloser)
                      mpLoopCloser->SetTracker(mpTracker)
                      mpLoopCloser->SetLocalMapper(mpLocalMapper)
3.SLAM.TrackRGBD：循环读取RGB图和Depth图，进行跟踪；计算前后两帧的间隔，如果时间小于跟踪时间则进行休眠等待
    3.1 检查是否需要进入仅跟踪模式：如果是仅跟踪模式，需要让LocalMapping线程暂停 --- 独占锁：mMutexMode
        mbActivateLocalizationMode为true，表示需要进入仅跟踪模式
            会循环等待LocalMapping线程停止，通过mbStopped判断 : mpLocalMapper->RequestStop()
                mbStopRequested = true  --- 独占锁：mMutexStop
                mbAbortBA = true    --- 独占锁：mMutexNewKFs
            通知Tracking线程运行仅跟踪模式：mbOnlyTracking = true
            mbActivateLocalizationMode = false
        mbDeactivateLocalizationMode为true，会让LocalMapping线程恢复
            通知Tracking线程暂停仅跟踪模式：mbOnlyTracking = false
            LocalMapping线程释放资源，重新开始进行局部建图
                将LocalMapping线程的暂停状态恢复：mbStopped=false
                将关键帧全部清除：mlNewKeyFrames.clear()
                mbDeactivateLocalizationMode = false
    3.2 检查是否需要重置：如果需要重置，需要通知Tracking线程也重置 --- 独占锁：mMutexReset
        通知Tacking线程重置：mpTracker->Reset()
            关闭观察器线程：mpViewer->RequestStop()
                mbStopRequested=true --- 独占锁：mMutexStop
            重置LocalMapping线程：mpLocalMapper->RequestReset()
                mbResetRequested = true --- 独占锁：mMutexReset            
            重置LoopClosing线程：mpLoopClosing->RequestReset()
                mbResetRequested = true --- 独占锁：mMutexReset
            清空关键帧数据库：mpKeyFrameDB->clear()
                mvInvertedFile.clear();
                mvInvertedFile.resize(mpVoc->size())
            清理地图：mpMap->clear()
                mspMapPoints.clear();
                mspKeyFrames.clear();
                mnMaxKFid = 0;
                mvpReferenceMapPoints.clear();
                mvpKeyFrameOrigins.clear();
            SLAM跟踪状态重置：mState=NO_IMAGES_YET
        mbReset = false
    3.3 获取相机位姿的估计结果：mpTracker->GrabImageRGBD(im,depthmap,timestamp)
        3.3.1 将输入的RGB图像转化为灰度图：cv::cvtColor(mImGray, mImGray, cv::COLOR_RGB2GRAY)
        3.3.2 将输入的深度图进行处理：imDepth.convertTo(imDepth, CV_32F, mDepthMapFactor)
        3.3.3 构建Frame对象：根据输入的RGB和Depth图构建Frame对象 mCurrentFrame = Frame(mImGray,imDepth,timestamp,mpORBextractorLeft,mpORBVocabulary,mK,mDistCoef,mbf,mfThDepth)
            # Frame.cc ExtractORB()
            3.3.3.1 ExtractORB
                # ORBextractor.cc operator()
                3.3.3.1.1 ComputePyramid
                3.3.3.1.2 ComputeKeyPointsOctTree
                    3.3.3.1.2.1 DistributeOctTree
                    3.3.3.1.2.2 computeOrientation
                        IC_Angle
            3.3.3.2 UndistortKeyPoints
            3.3.3.3 ComputeStereoFromRGBD
            3.3.3.4 ComputeImageBounds
            3.3.3.5 AssignFeaturesToGrid
        3.3.4 对返回的结果进行跟踪：Track()
    3.4 记录跟踪结果：包括跟踪状态、跟踪到的地图点、跟踪到的关键帧
        mTrackingState = mpTracker->mState;
        mTrackedMapPoints = mpTracker->mCurrentFrame.mvpMapPoints;
        mTrackedKeyPointsUn = mpTracker->mCurrentFrame.mvKeysUn;
4.SLAM.Shutdown
5.SLAM.SaveTrajectoryTUM # 相机位姿轨迹
6.SLAM.SaveKeyFrameTrajectoryTUM # 关键帧位姿轨迹
```
